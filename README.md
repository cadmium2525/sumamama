# 大乱闘スマママブラザーズ

Three.js で一から作った、スマブラ風の2人対戦アクションゲームです。PC とスマホ（横画面）で遊べ、PWA としてホーム画面に追加するとオフラインでも起動します。
キャラクターの3Dモデル・ステージ・エフェクト・効果音・BGM・アイコンは、すべてコードで生成しています（外部アセットなし）。

## GitHub Pages で公開する

公開用のファイルは `docs/` フォルダに出力済みです（ビルド済みを同梱）。

1. このフォルダを GitHub のリポジトリに push する（`node_modules/` は `.gitignore` 済み）
2. GitHub のリポジトリ → **Settings → Pages**
3. **Source: Deploy from a branch**、**Branch: `main` / `/docs`** を選んで Save
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます

ソースを変更したら、公開前に必ずビルドし直して `docs/` ごと push してください。

```bash
npm install
npm run build
```

## スマホで遊ぶ

- 公開URLをスマホのブラウザで開き、**「ホーム画面に追加」**（iPhone は共有ボタンから）するとアプリのように全画面・横画面で起動します。
- 一度開けば、以降は電波がなくても遊べます（サービスワーカーでキャッシュ）。
- 更新を公開すると、次に開いたときに自動で新しい版へ切り替わります。

## 開発

```bash
npm install
npm start          # 開発用サーバー http://localhost:5173 （ソースをそのまま配信）
npm run build      # docs/ に公開用ファイルを出力（JS は three.js ごと1ファイルに圧縮）
npm run preview    # docs/ の中身を http://localhost:5174 で確認
npm run icons      # アイコン画像を作り直す
```

開発用サーバーを起動すると、同じ Wi-Fi のスマホからアクセスできるアドレスも表示されます（ただしオフライン機能は HTTPS の公開版でのみ有効です）。

## 操作

### スマホ（タッチ）

- 画面の左側をなぞる：スティック（上に弾くとジャンプ）
- 右下のボタン：攻撃 / 必殺 / ジャンプ / スマッシュ / ガード / つかみ
- スティックの向き＋ボタンでワザが変わります。右上の II でポーズ。

### キーボード

| | P1 | P2 |
|---|---|---|
| 移動 | W A S D | ↑ ← ↓ → |
| ジャンプ | W / Space | ↑ / Num0 |
| 攻撃 | J / F | Num1 / , |
| 必殺ワザ | K / G | Num2 / . |
| シールド | L / H | Num3 / / |
| スマッシュ攻撃 | I / R | Num5 / ; |
| つかみ | U / T（シールド＋攻撃でも可） | Num4 / M |

- 1人プレイ（vs CPU）のときは P1 が両方のキー配置を使えます。
- ゲームパッド対応: A 攻撃 / B 必殺 / X・Y ジャンプ / LB・RB つかみ / LT・RT シールド / 右スティック スマッシュ / START ポーズ
- Esc / Enter でポーズ。ポーズ画面（または `` ` `` キー）で当たり判定を表示できます。

## 軽量化の工夫

- 公開版は esbuild で three.js ごと1ファイルにまとめ、使う部分だけを残して圧縮（JS 約 205KB gzip）
- キャラクターの部品は関節ごとに1メッシュへ結合して描画命令を削減、ステージの静的パーツも結合
- 影は負荷の高いシャドウマップをやめ、足元の軽い影（ブロブシャドウ）に
- スマホでは画質「軽量」（解像度控えめ）が既定。キャラ選択画面の「画質」で切り替え可能

```
server.js                   簡易サーバー（開発・プレビュー用）

src/touch.js                スマホのタッチ操作
src/battle.js               試合進行・当たり判定・カメラ
src/fighter.js              ファイターの状態遷移と物理
src/ai.js                   CPU の思考
src/smashball.js            スマッシュボールと切りふだ演出
src/stage.js                ステージ（当たり判定と見た目）
src/chars/                  キャラ性能・ワザデータ・アニメーション
src/models/                 3Dモデル（Three.js でプロシージャル生成）
src/render/                 描画設定・エフェクト
dev/                        開発用（参考画像との比較ページ、自動テスト用ハーネス）
```
